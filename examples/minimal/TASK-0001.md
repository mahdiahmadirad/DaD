# TASK-0001: Add a readiness endpoint

## Status

Ready

## Outcome

Add an HTTP readiness endpoint that reports when the Pulse process is able to
serve requests.

## In scope

- Add `GET /ready`.
- Return a stable JSON response.
- Add focused endpoint tests.

## Out of scope

- dependency checks;
- authentication;
- metrics; and
- changes to the existing liveness endpoint.

## Constraints

- The endpoint must not perform network or storage access.
- Existing public behavior must remain unchanged.

## Acceptance conditions

- `GET /ready` returns status `200` while the process is serving requests.
- The response media type is `application/json`.
- The response body is exactly `{"status":"ready"}`.
- Other HTTP methods on `/ready` are rejected by the existing router behavior.
- Focused endpoint tests and the existing test suite pass.
