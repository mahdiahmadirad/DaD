# Relay Working Agreement

These instructions apply to humans and AI coding agents working on Relay.

Before implementation:

1. Read `PROJECT-VISION.md`.
2. Read the requested TASK.
3. Read every accepted ADR and approved SPEC linked by that TASK.
4. Inspect the affected implementation, tests, and version-control state.

Accepted ADRs govern architectural choices. Approved SPECs govern behavior.
The active TASK governs current scope. If these sources conflict or are
insufficient, stop and request resolution.

Implement only the active TASK, preserve unrelated work, and add proportionate
verification. Record checks actually performed in the TASK and stop when it is
complete. Do not begin a follow-up task without explicit approval.
