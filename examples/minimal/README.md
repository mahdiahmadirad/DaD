# Minimal example: Pulse

Pulse is a fictional HTTP health service used to show the smallest practical
DaD adoption.

This example contains:

- [PROJECT-VISION.md](PROJECT-VISION.md) for durable direction;
- [AGENTS.md](AGENTS.md) for contributor rules; and
- [TASK-0001](docs/tasks/TASK-0001.md) for one bounded change.

There is no ADR because the task requires no consequential architectural
decision. There is no SPEC because the task's acceptance conditions are
sufficient for this small, local behavior. If later work makes the endpoint a
shared contract or introduces a consequential design choice, the project can
add the appropriate document then.

The example contains documentation only. `TASK-0001` is `Ready`, not
implemented, and no completion evidence is claimed.

For the methodology behind this example, see the DaD
[overview](../../docs/OVERVIEW.md) and
[workflow](../../docs/WORKFLOW.md).
